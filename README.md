# rebattle

**drop. bounceback. rebattle.**

A tournament manager for head-to-head double-elimination events, built for a wakeboard competition but sport-agnostic. Riders who lose once drop to the Losers bracket for a second chance; the top two of each bracket cross over into a Final 4.

## Format

- **Winners bracket**: a classic knockout, filled up to a power of two with random byes.
- **Losers bracket**: lose once in the Winners bracket and you drop here; lose again and you're out. Each round is a fresh random draw that mixes survivors with the latest drop-ins. It opens once Winners rounds 1 and 2 are done.
- **Final 4 (crossover)**: Semifinal 1 = WB 1st v LB 2nd, Semifinal 2 = WB 2nd v LB 1st. Semifinal winners ride the Grand final, the others the Small final.
- Heats are single run or best of 3. Every field size plays exactly 2N heats.

## Features

- Setup with a time estimate, random draw, then one tap per heat to record the winner. Undo, rename riders or the tournament at any time.
- Live bracket view: connector lines, path highlighting on hover, drop-in markers, shared places for riders out in the same round, a legend. On phones, brackets switch to round tabs.
- **Replay video**: a vertical (1080×1920) animated recap of the whole event, or one rider's journey, exported as a video file and shareable from a phone.
- Everything is saved in the browser; export/import JSON to back up or move to another device.

## Run it

No build step and no dependencies. Serve the folder with any static server:

```sh
python3 -m http.server 8787
# open http://127.0.0.1:8787
```

Opening `index.html` straight from the disk also works, but browsers don't show the tab icon for `file://` pages, and saved tournaments are kept per address (a `file://` copy and a `http://` copy don't share data; use Export/Import to move them).

## Tests

```sh
node --test
```

Plays thousands of random tournaments (4–40 riders, both formats) and checks the bracket invariants, plus the import checks. Runs on every push via GitHub Actions.

## Project layout

| Path | What |
| --- | --- |
| `index.html`, `styles.css` | The page and all styles |
| `js/bracket.js` | Bracket engine: pure logic, no DOM. Creates tournaments, records results, advances riders |
| `js/storage.js` | Saving in the browser, JSON export, and import validation (`Store`) |
| `js/ui.js` | Builds the screens as HTML, draws connector lines, tabs and path highlighting |
| `js/replay.js` | The replay video: scene timeline, canvas drawing, player and video export |
| `js/app.js` | App state and all click handling |
| `fonts/` | Funnel Display + Funnel Sans, bundled so the app works offline (SIL OFL, see `fonts/OFL.txt`) |
| `icons/` | Favicon and home-screen icons, generated by `tools/make-icons.py` |
| `tests/` | `node --test` suite |

## Roadmap

1. Hosting on Cloudflare Pages with a custom domain.
2. Cloud saving: one Durable Object per tournament (EU), organiser login via Cloudflare Access, offline-tolerant saves.
3. A public read-only link with live updates, and a "follow me" card for riders (next heat, opponent, how long until they ride).
4. Split `ui.js` / `replay.js` into ES modules and add a viewer mode as part of step 2–3.
