# Security

Please don't report security problems in public issues.

Report them privately through GitHub: the repository's **Security** tab, **Report a vulnerability**. You'll get an answer within a few days, and a fix is released as soon as it's ready; we'll credit you in the release notes unless you'd rather not be named.

What counts: anything that lets someone change a tournament they don't own, read an organiser's email or other private data, get past the organiser login, or run code on rebattle.app or in someone else's browser.

Only the latest version, the one running on [rebattle.app](https://rebattle.app), is supported.
